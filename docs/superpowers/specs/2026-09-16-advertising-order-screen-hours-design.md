# Автоматический интервал по рабочим часам экранов

## Цель

На странице создания рекламного заказа после выбора экранов автоматически
устанавливать общий рабочий интервал выбранных экранов вместо дефолтного
`08:00–23:00`.

## Поведение

- Общий интервал определяется пересечением рабочих часов всех выбранных
  экранов на всех датах текущей сетки заказа.
- Начало интервала — самое позднее начало работы.
- Конец интервала — самое раннее окончание работы.
- При отсутствии выбранных экранов используется `08:00–23:00`.
- Автоматически изменяется только окно, созданное системой.
- Ручное изменение границ снимает с окна статус автоматического.
- Добавление нового окна пользователем не меняет автоматический интервал.
- После ручного изменения или добавления окна последующие изменения набора
  экранов не затрагивают пользовательские окна.
- Если пересечение рабочих часов отсутствует, поля автоматического окна
  очищаются; пользователь может вручную задать окно или добавить новое.

## Архитектура

Изменения выполняются в Stimulus-контроллерах формы:

- `_form.html.slim` помечает исходное окно как автоматическое и передаёт
  контроллеру данные о рабочих часах экранов.
- `order_screen_picker_controller.js` после изменения выбора экранов отправляет
  событие пересчёта интервала.
- `order_windows_controller.js` пересчитывает только окно с признаком
  автоматического. Поля этого окна при ручном вводе снимают признак.
- Пользовательские окна остаются обычными полями формы и продолжают
  отправляться без специальных параметров.

Серверные модели, контроллеры и формат параметров заказа не меняются.

## Тестирование

- Добавить регрессионные проверки Stimulus-поведения выбора экранов:
  - два экрана формируют пересечение рабочих часов;
  - отсутствие выбранных экранов возвращает `08:00–23:00`;
  - ручное изменение автоматического окна сохраняется при следующем выборе;
  - добавленное второе окно не изменяется автоматически.
- Запустить относящиеся к форме системные и JavaScript-тесты в web-контейнере.
