# Замена видеоролика в заказе — дизайн

## Цель

Добавить оператору возможность заменить видеоролик на форме редактирования
заказа в админке.

## Требования

- На форме редактирования показывать готовые медиа-ассеты организации заказа.
- Разрешать замену только для заказа со статусом `draft`.
- Принимать только медиа-ассет, принадлежащий организации заказа и имеющий
  статус `ready`.
- Сохранять существующую сетку заказа, если пользователь её не изменяет.
- Для активных и других нечерновых заказов не показывать возможность замены и
  не позволять изменить ролик через поддельные параметры запроса.

## Дизайн

Использовать существующий select выбора медиа-ассета, который сейчас доступен
только на форме создания. Контроллер будет загружать коллекцию доступных
ассетов и на `edit`, а параметр `media_asset_id` будет добавлен в набор
атрибутов обновления только для черновика.

Проверка будет выполняться на сервере через выборку ассета из организации
заказа с ограничением `ready`. Для нечернового заказа параметр ролика не будет
применяться. Остальные атрибуты и обработка сетки останутся в существующем
потоке `update`.

## Ошибки и UX

- Если передан недоступный ассет, обновление не меняет текущий ролик и
  возвращает форму с ошибкой валидации.
- Для нечерновых заказов select замены не отображается.
- После успешной замены оператор возвращается на страницу заказа с обычным
  уведомлением об обновлении.

## Тестирование

Request-спеки проверят:

1. отображение select на edit чернового заказа;
2. успешную замену на готовый ассет той же организации;
3. сохранение линий и дней сетки;
4. невозможность выбрать ассет другой организации или неготовый ассет;
5. невозможность заменить ролик у активного заказа;
6. отсутствие поля замены для нечернового заказа.
