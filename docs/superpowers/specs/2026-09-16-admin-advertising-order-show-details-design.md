# Детали заказа на странице показа — дизайн

## Цель

Показать оператору на странице заказа все основные параметры размещения и
медиафайла без перехода в редактирование.

## Отображаемые данные

- даты размещения как группы непрерывных дней;
- общее количество уникальных дней;
- временные интервалы показа;
- имя файла медиа-ассета;
- длительность медиа-ассета в секундах;
- тип контента;
- категория контента;
- общее количество показов.

## Дизайн

В существующий `show.html.erb` добавить отдельный блок деталей в текущем
Flowbite-оформлении. Форматирование вынести в `AdvertisingOrdersHelper`, чтобы
view не содержал алгоритмов.

Даты берутся из всех `advertising_order_line_days`, сортируются и объединяются
в непрерывные диапазоны. Например, даты `01.06`, `02.06`, `03.06`, `07.06`
отображаются как `01.06–03.06, 07.06`; общее количество дней равно `4`.
Временные интервалы отображаются в формате `HH:MM–HH:MM`.

Для отсутствующих данных используется существующий перевод
`admin.crud.none`. Тип и категория контента форматируются через существующие
enum-переводы `admin_enum_label`.

## Тестирование

Request-спека проверит, что страница показа содержит:

1. непрерывные диапазоны дат с пропуском;
2. общее количество дней;
3. интервалы показа;
4. имя, длительность, тип и категорию медиафайла;
5. общее количество показов.
